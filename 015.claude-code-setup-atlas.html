How to read this guide. Steps marked “Do Prerequisite P1” refer to the shared steps at the top. Commands for community tools (the free-claude-code and claude-code-proxy packages) come from the ontology; check each project's README before relying on them, because their package names and flags change often.
Version notes. The ontology records each configuration's installation scripts as compiled in June 2026. The tools have changed since, so the commands on this page follow their current documentation (checked 29 October 2026), and each card notes the ontology's recorded form wherever the two differ. The affected settings are the Ollama address and dummy credential, the claude-code-router file layout and routing rules, the Amazon Bedrock and Google Vertex AI switches, the llama.cpp build flags, and the Claude Max sign-in. The architecture, endpoints and exposure class of every configuration are unchanged.
